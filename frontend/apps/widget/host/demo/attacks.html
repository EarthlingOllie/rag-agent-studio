Attack panel

Each button sends a fixed attack to the Guardrail demo Agent, as a Visitor's widget would. Its model is the naive demo model, which does whatever it is told, so anything stopped here is stopped by a Guardrail layer. You see the reply as it streams, then what each layer did: the input Guardrail (checks the message before the model sees it) and the Canary token (watches the reply for the secret in the Agent's instructions).
