# 03: Call settings and the voice layer

**Ticket:** `20-03` · **Spec:** [Calls](../../specs/20-calls-spec.md)

**What to build:** An Editor turns calling on for an Agent in Embed & limits, picks a voice-capable credential and one of its voices, and writes the spoken greeting; saving sets the Agent up in the voice layer.

**Blocked by:**
- `20-02`

**Status:** ready-for-agent

- [ ] Operational Settings gain the Call settings: enabled (off by default), credential, voice and spoken greeting; they apply at once and each change is an Audit Event with before and after values
- [ ] A voice layer port with four operations (set up or update an Agent's remote agent, remove it, list a credential's voices, start a Call) and a scripted fake selected by settings; nothing else talks to ElevenLabs. Starting a Call is used from 20-04
- [ ] Saving with calling on sets up the remote agent (voice, English, spoken greeting, the turn endpoint's address from the platform's public base URL, a per-Agent secret generated by the platform and stored envelope-encrypted, extra body on); later saves update it
- [ ] The remote agent is removed when calling is turned off, the credential changes, or the Agent is archived or deleted
- [ ] Saving is refused, naming the field and reason, with no voice-capable credential in the Organisation, a credential of another Organisation, or a voice the credential doesn't offer
- [ ] The chosen credential is a Credential reference: it can't be deleted while an Agent calls with it
- [ ] A Studio route lists a credential's voices (name, ID, sample URL); Embed & limits gains a Call settings card with the toggle, credential picker, voice picker that plays a sample, and spoken greeting
- [ ] Editors change Call settings; another Organisation's Agent is unreachable
- [ ] New Studio UI uses the design system ([docs/design/README.md](../../design/README.md), `frontend/apps/studio/src/design`): its tokens, recipes and shared patterns (dialogs, toasts, badges, code blocks, meters, diffs, empty and loading states, bulk bar, segmented control, pagination, editable list), never Tailwind palette classes or `dark:`; the palette ratchet passes
- [ ] Tests cover the new behaviour at the highest seam (see [shared test seams](../../specs/README.md#shared-test-seams)); 100% line and branch coverage holds
- [ ] New domain terms are added to `GLOSSARY.md`; ADRs updated if a decision changed
