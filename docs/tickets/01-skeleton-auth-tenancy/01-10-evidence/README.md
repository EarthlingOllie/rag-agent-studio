## Decisions and notes (best guesses recorded instead of asking)

- **The choice is remembered on the server, per Member.** "Persists across reloads" is met by the address alone. The API also remembers the last choice, so `/` and a later sign-in on another device open the same Organisation. A Member who has left the remembered Organisation gets their first one.
- **Redis, not a database column.** A `members.active_organisation_id` column would need a migration. 01-09 is being built at the same time from the same base and may add one too, which would leave Alembic with two heads. The choice is a convenience, and losing it only means the first Organisation opens, so a Redis key per Member with no expiry is enough. If it should become durable, it can move to a column later without changing the API.
- **The path stays the authority.** The remembered Organisation is never used to authorise anything. Organisation-scoped routes keep `{organisation_id}` in the path, so a request can't reach an Organisation by switching, and two tabs on two Organisations each keep working.
- **Opening a different Organisation by address doesn't change the remembered one.** Only the switcher changes it. That keeps a shared or bookmarked link from moving the Member's default without them choosing it.
- **Switching opens Projects.** Pages below an Organisation can name resources of that Organisation, and the Member's role can differ (for example, Owner-only tabs). So switching lands on Projects rather than keeping the current sub-page.
- **Joining doesn't switch.** Accepting an invite adds the Membership without moving the remembered choice (the accept page still opens the joined Organisation's Projects by address).
- **Not an Audit Event.** Switching is a navigation preference, not a membership or security change, so nothing is recorded.
- **An existing e2e check changed.** In `invites.spec.ts`, an existing Member who joins now has two Organisations, so the header shows the switcher instead of the plain name. The check now reads the switcher's chosen option.
