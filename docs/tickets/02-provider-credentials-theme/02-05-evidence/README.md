## Decisions and notes (best guesses recorded instead of asking)

- **Where resolution lives.** The pure resolution function and the contrast check are TypeScript in `@studio/ui`, because both the Studio preview and the React widget (spec 06) render with it, and the preview must follow unsaved edits without a round trip. For spec 06's server-rendered shell, `themeStylesheet` produces the CSS to inline; if the shell is rendered by the API in Python, that ticket must either inline the stylesheet the widget bundle builds or port the function (it is ~20 lines). The API stores and validates but never resolves.
- **The default Theme** is defined in the API (`DEFAULT_THEME` in `schema.py`) and mirrored as `DEFAULT_THEME` in `@studio/ui` for tests and the widget's fallback. The Studio always shows what the API returns.
- **Contrast pairs and thresholds.** Text pairs need 4.5:1 (normal text). The accent is used for links and focus outlines on the surface, so it needs 3:1. The muted token is text, so 4.5:1. Only schemes the mode can show are checked, so a light-only Theme isn't warned about unused dark values.
- **Radius range** 0 to 24 px, whole numbers.
- **Font allowlist** (12): Inter, Roboto, Open Sans, Lato, Source Sans 3, Nunito, Work Sans, IBM Plex Sans, Merriweather, Lora, Source Serif 4, JetBrains Mono. The resolved font stack falls back to `ui-sans-serif, system-ui, sans-serif`. `GET /api/themes/fonts` is public, like the font names themselves.
- **Launcher position** is bottom-right or bottom-left (the spec says "the bubble's corner"; top corners would cover host-page navigation). The position is kept when the launcher is inline but not shown.
- **Saving replaces the whole Theme** (`PUT`). The Studio sends the full draft.
- **Audit detail.** `theme.updated` records only what changed; a no-op save records nothing and leaves the default unstored.
- **Event times** come from the request's clock reading. Two concurrent saves can therefore list in either order; the concurrency test checks the chain of `before`/`after` values instead.
- **Migration number.** `0007_themes` revises `0006_invites`. Other tickets building in parallel may also add a `0007`; whichever merges second must re-point its `down_revision`.
