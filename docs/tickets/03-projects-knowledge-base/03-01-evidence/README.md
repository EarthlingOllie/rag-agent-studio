## Decisions and notes (best guesses recorded instead of asking)

- **Who does what.** Spec 03 user stories 1, 4 and 5 are for Editors and story 6 is for Owners. So create, rename, describe and archive are open to every Member, and restore is Owner-only.
- **Counts.** `document_count` and `agent_count` are in every answer. They are always 0 for now, because Documents arrive with 03-02 and Agents with 04-01. `app/projects/service.py::_summaries` is where those tickets add the real counts.
- **"Stops it serving".** Nothing serves yet: there are no uploads, Agents or widget. The archived state is enforced through one gate, `active_project`, which every changing or serving path must call. It already refuses renaming and re-archiving with 409. Later tickets (uploads in 03-02, Agents, and the widget) call it too. Reading an archived Project stays allowed, so its page can show Restore.
- **Archived list.** It is a query flag (`GET …/projects?archived=true`), not a separate route. In the Studio it is a toggle on the Projects page, not a separate page.
- **Names.** Names don't have to be unique; spec 03 asks for none. Names and descriptions are trimmed. An empty name is refused with 422; an empty description is allowed.
- **Idempotency.** Archiving an archived Project, or restoring an active one, is 409 and records nothing. It is not a silent no-op, so the Audit trail stays exact.
- **Sorting.** The list is by `lower(name)`. On the compose database (collation `en_US.utf8`), sorting by plain `name` gives the same order. That mutation is equivalent, so it isn't in the mutation list, but the test uses mixed-case names to catch it on a `C`-collation database.
- **Rename isn't an Audit Event.** The criterion and story 35 list create, archive, restore and delete only. Rename can be added later without changing anything here.
- **Migration number.** `0007_projects` follows `0006_invites`. Other tickets built in parallel (01-12, 02-01, 02-05) may also add a `0007`. Whichever merges second must re-point its `down_revision`.
- **Routes.** The Project page uses child routes for its tabs, so each tab has its own address. Documents is the index tab.
