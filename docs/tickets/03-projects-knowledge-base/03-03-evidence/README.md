## Decisions and notes (best guesses recorded instead of asking)

- **`listChunks` changed shape** from a bare list to a page. Nothing outside this repo calls it, and the Studio didn't use it before this ticket, so no compatibility route was kept.
- **Offset pagination**, not a cursor: Chunks of one edition are immutable and ordered by `ordinal`, so offsets are stable, and the viewer needs a total ("of 120").
- **Download as a redirect** (307) instead of returning the URL in JSON; see criterion 2. The presigned URL lives 5 minutes by default (`DOWNLOAD_URL_TTL_SECONDS`).
- **Markdown in `getDocument`.** The markdown comes with the Document in one call; it is read from the object store on each open. Very large conversions would make this response large; splitting it out is easy if that becomes a problem.
- **Markdown rendering** uses `react-markdown` 10.1.0 and `remark-gfm` 4.0.1 (Docling emits GFM tables). Raw HTML in the markdown is not rendered (react-markdown's default), so a Document can't inject markup into the Studio. Element styles are in `index.css` under `.markdown`, since Tailwind's reset removes them.
- **Guardrail flags and Tags** in the viewer are tickets 03-07 and 03-06; this ticket's viewer has no flag or Tag UI.
- **The Documents tab stays highlighted only on the list.** The tabs use exact matching, so on the viewer no tab is active; the "All Documents" link leads back.
- **Studio test timing.** The viewer's tests give their first query 5 s (`LOAD`) and the two long ones a 15 s test timeout, because on this shared, overloaded machine the first render in a test file takes 2–3 s.
