## Decisions recorded (best guesses, no human asked)

- **AZs are an explicit input**, not looked up, to satisfy Checkov CKV_AWS_394 and keep plans stable.
- **One private route table and one NAT** in both modes. ADR-0010 and spec story 6 ask for one managed NAT gateway, not one per AZ.
- **Interface endpoints in both private subnets.** That costs roughly 4 endpoints × 2 AZs × about $8 a month (eu-west-2 list price, unverified here), plus data processing. It is the ticket's stated way to cut NAT traffic. Spec ticket 09-06 owns the documented monthly cost.
- **Checkov skips, each justified inline:** CKV2_AWS_11 (VPC flow logs: paid ingestion and storage the short-lived demo does not need), CKV2_AWS_41 (`fck-nat` makes no AWS API calls, so it gets no IAM role) and CKV_AWS_126 (detailed monitoring costs more than the NAT instance itself).
- **The VPC's default security group is managed with no rules**, so anything left on it is isolated.
- **AWS provider `~> 6.72`**, pinned to 6.72.0 by committed `.terraform.lock.hcl` files in `infra/modules/network` and `infra/envs/demo`. They hold the `h1` hash plus a `zh` hash for every platform zip in HashiCorp's SHA256SUMS. CI's registry install accepted them.
- **`infra/envs/demo` now has `provider "aws"`** (region from `aws_region`, default `eu-west-2`, matching the workflows) with `default_tags`. TFLint needs this once the environment requires the AWS provider. It is the only shared file likely to overlap with 09-01 or 09-06.

## Sandbox notes

- **Provider download.** The sandbox's egress proxy blocks `registry.terraform.io` (403). The AWS provider 6.72.0 came from `releases.hashicorp.com`, checked against HashiCorp's SHA256SUMS, and was served to Terraform through a filesystem mirror in `TF_CLI_CONFIG_FILE` ([provider-mirror.log](provider-mirror.log)). The GPG signature on SHA256SUMS was not checked. CI uses the public registry, which verifies signatures.
- **TFLint AWS ruleset.** `api.github.com` and `github.com` release downloads are blocked here, so `tflint-ruleset-aws` could not be installed or tried. `infra/.tflint.hcl` stays on the bundled Terraform ruleset (preset `all`). Adding the AWS ruleset is spec-wide work and is left for a later spec 09 ticket.
- Checkov runs offline (`skip-download: true`), the same as in CI.
