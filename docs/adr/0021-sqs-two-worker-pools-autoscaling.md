# AWS runtime, revised: SQS, two worker pools, autoscaling, no interface endpoints

This amends [ADR-0010](0010-aws-runtime-shape.md). The demo serves a handful of clients but has to show that it scales, so the fixed task counts become elastic and the parts that cost money without helping it scale go.

**SQS is the job broker; Redis stays for everything else.** ADR-0010 chose Redis as the broker because Celery's SQS transport is weaker and Redis was already needed. Two things changed. Workers now scale on queue depth, and SQS reports each queue's depth to CloudWatch with no code of ours, where Redis would need the API to measure and publish it. And since [ADR-0020](0020-database-is-the-record-of-jobs.md) the broker is only a wake-up call, so the transport's gaps (no worker inspection, no long delays) cost nothing we rely on. Redis still holds sessions, sign-in throttling, rate limits, Token Budgets and the worker health probe's reply. Locally, a Floci container provides SQS, so the local stack and AWS use the same transport.

**Two worker pools, one queue each.** The general pool runs on Fargate Spot, 1 to 3 tasks: ingestion, Re-embeds, deletions, Live Verdicts, the scheduled jobs and the sweeper. All of these restart for free, so a Spot interruption costs nothing but time. The runs pool runs on regular Fargate, 0 to 2 tasks: Evaluation Runs and Suggestion runs, which are long, spend an Organisation's money and are not resumed. Keeping them apart also stops a long Run holding up ingestion. Both pools scale on their queue's depth; the API scales 1 to 3 on CPU; Beat stays one task. A worker protects its task from scale-in while it holds a job, and a deploy waits up to 30 minutes for running jobs before stopping them.

**Private subnets and `fck-nat` stay; the four interface endpoints go.** The endpoints (ECR API, ECR Docker, Logs, Secrets Manager) were about a quarter of the always-on cost and only kept some traffic off the NAT. Image layers still come through the free S3 gateway endpoint. We considered moving tasks to public subnets, which would also remove the NAT: it is simpler and slightly cheaper, but "no public addresses on application tasks" is worth about 11 USD a month to keep.

**Unchanged:** Secrets Manager, the separate KMS key for Provider Credentials (ADR-0006), CloudFront in front of one ALB (ADR-0011), and the database and cache sizes. Read replicas would need the application to route reads and are not built.

We considered scaling workers on CPU, which needs nothing new, but a worker waiting on a model provider looks idle, so Evaluation Runs would never trigger it. We considered letting the general pool scale to zero as well; Beat's scheduled jobs and the sweeper would wake it every minute, so it would need a third always-on service to hold them, and the first upload after idle would wait minutes for a multi-gigabyte image.
