# Evaluation Cases outlive the Retention Window

An Evaluation Case added from an Agent Message copies the Visitor's question into the Agent's Evaluation Set, and the Purge never clears it: it is kept until an Editor deletes it. A regression set that empties itself after the Retention Window would stop catching the failures it was built from, so a case is treated as the Editor's deliberate copy rather than as Message text. To keep that exception small, the copy is shown to the Editor and editable before it is saved, the case keeps no link back to the Conversation or the Visitor (so the Conversation itself is still purged and deleted as before), adding a case from a Message and deleting a case are Audit Events, and nothing else outside `messages` holds Message text. Don't "fix" this by purging cases with their source Conversation, or by linking cases back to it.
